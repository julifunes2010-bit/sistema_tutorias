##  Sobre el proyecto

**Sistema de Tutorías ProA** es una aplicación web desarrollada como proyecto escolar utilizando **Vue.js**.

La plataforma busca facilitar la organización de las tutorías dentro de una institución educativa, centralizando diferentes funciones en un mismo sistema.

El proyecto incluye un sistema de inicio de sesión, registro de usuarios, recuperación mediante código de verificación, consulta de cursos, reportes y configuración de la cuenta.

>  Actualmente es un **prototipo frontend**, por lo que algunos datos son simulados y determinadas funciones pueden ampliarse con un backend en futuras versiones.

---

#  Objetivos

El objetivo principal es desarrollar una plataforma sencilla y accesible para organizar las tutorías escolares.

### Objetivos específicos

-  Crear un sistema de inicio de sesión.
-  Permitir el registro de usuarios.
-  Incorporar recuperación de acceso.
-  Verificar códigos de recuperación.
-  Consultar cursos y docentes.
-  Mostrar reportes.
-  Administrar configuraciones.
-  Implementar navegación entre páginas.
-  Crear un diseño responsive.
-  Aplicar conocimientos de desarrollo web y Vue.js.
